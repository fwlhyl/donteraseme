# 1.0

既然我们现在是头脑风暴时间（不写代码），那我就从技术实现和表现力的角度，来和你碰撞一下这个序章的落地细节。在我们的 2D 俯视角框架下，我设想了以下几个维度的表现方式，你看看哪个最对味：

### 1. 现实世界与里世界切入（过场动画）
- 表现手法 ：开局全黑，只有音效和字幕。
  - 音效 ：翻找抽屉的声音 -> 小男孩得意的窃笑声 -> 沉重的橡皮擦摩擦纸张的声音（沙沙沙...）。
  - 字幕 ：“看我把你画的这些丑东西全擦掉！”
  - 转场 ：屏幕中央被“擦”出一条亮光，镜头猛地拉近，主角在一个粗糙的铅笔起稿线世界中醒来。
### 2. 画布城（真实地图感）
- 既然你提到想要像《传奇》那样有实打实的地图，在我们当前的 2D 俯视角下，我们可以这样做：
  - 美术预渲染背景 ：不再是纯黑背景加网格，而是加载一张带有街道、画板建筑、颜料喷泉的“线稿城市地图”。
  - 物理阻挡 ：我们可以根据这张地图的街道画上空气墙（碰撞体），主角只能在狭窄的街道巷子里穿梭，这就有了“城镇”的空间感。
  - 繁华氛围 ：街道上可以放一些四处游荡的“火柴人市民”（NPC）。
### 3. 巨型橡皮擦与跑酷逃亡（核心玩法）
这是序章的高潮。既然是逃亡和跑酷，核心情绪就是**“无力感” 和 “紧迫感”**。我构思了两种跑酷方案：

- 方案A：强制卷轴的“吞噬”跑酷（推荐，压迫感极强）
  - 机制 ：镜头开始强制向下（或向右）移动，屏幕后方是一个占据整个屏幕宽度的 巨大阴影/白光（代表弟弟的橡皮擦） ，它以极快的速度推进。
  - 视觉 ：它经过的地方，画布城的精美背景、火柴人市民，全部被“物理抹除”，变成一片虚无的深渊。
  - 跑酷点 ：主角没有任何武器（无法攻击），只能疯狂往前跑。路上会有“散落的铅笔盒”、“未干的颜料坑”作为障碍物减速，你需要利用纯粹的走位甚至“冲刺（Dash）”技能来躲避障碍，千万不能被后方的橡皮擦追上。
- 方案B：弹幕迷宫逃亡（偏向操作精细度）
  - 机制 ：天空中不断落下巨大的“橡皮印章”（红圈警告 -> 砸下，类似轰炸区）。同时前方涌来大量的“橡皮擦士兵”。
  - 跑酷点 ：你不需要打败他们（你也打不死），你只需要在枪林弹雨和轰炸中寻找缝隙，跑到地图的最深处（比如画布城的地下避难所入口）就算通关。
### 4. 序章的结局（承上启下）
- 逃到终点时，主角可能还是被逼入绝境（比如前方没路了）。就在巨型橡皮擦即将抹除主角的瞬间，主角体内爆发出了第一道“色彩”（觉醒），抵挡住了致命一击，随后坠入下层空间……紧接着标题出现： 《Dont Erase Me!》 。然后顺理成章地衔接到我们刚刚做好的第一幕（保护画眼）。



# 2.0

一开始主角可以在画布城闲逛，然后橡皮来了，随后画布城就变成了方案B中的“迷宫”（主角要逃离这里），随后镜头开始强制向右移动，它经过的地方，画布城的精美背景、火柴人市民，全部被“物理抹除”，变成一片虚无的深渊。同时还会出现橡皮擦士兵和红圈警告的轰炸区。逃到终点时，主角可能还是被逼入绝境（比如前方没路了）。就在巨型橡皮擦即将抹除主角的瞬间，主角体内爆发出了第一道“色彩”（觉醒），抵挡住了致命一击，随后坠入下层空间……紧接着标题出现： 《Dont Erase Me!》 。然后顺理成章地衔接到我们刚刚做好的第一幕（保护画眼），主角拿起一把掉落的武器开始了准备战斗。
