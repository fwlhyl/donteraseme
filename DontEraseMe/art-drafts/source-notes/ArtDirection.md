# 《Dont Erase Me》2D 美术方向 v0.2（已确认）

> 历史方案：2026-10-08 用户已确认改为电脑画板式稚拙涂鸦，背景与角色、敌人统一，UI 保持原样。当前方向、资源规格及动态实现见 [DoodleArtImplementation.md](../../docs/DoodleArtImplementation.md)，新风格参考在 `../production-candidates/doodle-v1/style-reference.png`。下文的水彩排除规则、32 px / 8 帧规格及唯一母风格声明仅记录旧方案，不作为当前生产要求。

## 一句话方向

**手绘速写本战场**：创作者在一本旅行速写本中以马克笔、墨线与颜料留下痕迹，对抗将一切抹白的橡皮擦教团。游戏内保持高清伪像素的辨识度；菜单、HUD、结算和地图装饰全部共享同一套「手帐 / 画夹 / 便签」视觉语法。

> 2026-10-01：用户确认此方向；后续所有美术候选均以 `../concept-boards/03-unified-sketchbook-style.png` 为唯一母风格。此前的水彩向候选仅保留作历史草稿，不作为生产参考。

参考图属于**手绘旅行速写本 / 马克笔漫画插画**：略微抖动的黑色线稿、扁平马克笔填色、有限的铅笔排线、暖纸张底和拼贴式版面。它不是水彩晕染风，也不是像素风。`../concept-boards/03-unified-sketchbook-style.png` 是本方向的全项目候选总览。

32×32 战斗精灵不可依赖细腻纹理，因此缩小后保留“黑轮廓 + 两到三块马克笔色 + 一个手绘符号”；大界面才保留纸张颗粒、胶带和速写排线。

## 全局视觉规则

| 元素 | 规则 |
| --- | --- |
| 线条 | `#20212A` 深墨线，战斗单位外轮廓 2 px（原尺寸），内细节最多 1 px。 |
| 纸底 | `#F7F0DF`，使用细颗粒纸纹、淡铅笔网格或页面折痕；战斗地面不能高对比。 |
| 玩家阵营 | 高饱和但单人只用「主色 + 点缀色 + 墨线」，保证一眼辨识。 |
| 敌方阵营 | 灰、白、炭黑为主体；功能预警只用一小块冷蓝/洋红/黄。 |
| 颜料 | 青 `#2AA9E0`、群青 `#3757C9`、朱红 `#EF4B4B`、黄 `#F4BF32`、洋红 `#D84896`、紫 `#8158BC`、薄荷 `#47BCA6`。 |
| 可读性 | 所有攻击和敌人须有深墨或浅纸二选一的对比边；绝不靠半透明颜色区分危险。 |
| 笔触 | 颜色是干爽的马克笔 / 蜡笔式不均匀填色；用少量斜向铅笔排线补阴影。不要大面积水彩晕染、写实高光或平滑渐变。 |
| 拼贴 | 所有非战斗界面从同一套素材库取：胶带、回形针、图钉、撕纸边、画夹、速写本线圈。它们是分区与强调，不是随机贴满屏。 |

## 角色方案

概念参考：`../concept-boards/01-characters-concept.png`。最终战斗资源统一为：32×32 原图、8 帧一排、左右两向镜像或独立绘制；屏幕以 1.5× 最近邻放大。每名角色只保留帽型/发型、工具、主色三项“远读标志”。

| 角色 | 远读剪影 | 主色 | 战斗识别钩子 |
| --- | --- | --- | --- |
| 收藏家 | 大背包、画筒 | 苔绿 + 金黄 | 金币/小卡片飞散。 |
| 水彩插画师 | 宽檐帽、长刷 | 青蓝 | 笔刷尾端有清晰的蓝色滴墨。 |
| 数字板绘师 | 耳机、矩形数位板 | 紫黑 + 洋红 | 青色像素点和一台小浮游笔。 |
| 书法家 | 高髻、长笔 | 黑 + 朱红 | 夸张长笔和红色束带。 |
| 水墨画家 | 宽袖、墨瓶 | 靛黑 + 灰蓝 | 袖摆的干笔飞白形状。 |
| 街头涂鸦客 | 帽、口罩、喷罐 | 青 + 洋红 | 喷罐与双色肩包。 |
| 古典油画家 | 贝雷帽、圆调色板 | 赭红 + 黄 | 圆盘是不可替代的强轮廓。 |
| 速写漫画家 | 护目镜、速写本、铅笔 | 黑白 + 黄 | 本子矩形和黄色围巾。 |

## 武器与反馈方案

概念参考：`../concept-boards/02-weapons-vfx-concept.png`。武器图标 48×48，局内投射物 8–24 px，爆发效果控制在 64–128 px；静态图标可用纸纹，实战投射物不用。

- 圆头画笔：青色、圆头、连贯弧线；命中是带墨边的花瓣形点染。
- 钢笔：群青黑、尖锐直线；暴击留一颗白色高光墨滴。
- 喷漆罐：洋红/青双色雾；危险边缘用 1 px 深色散点，不作整片模糊。
- 颜料桶炸弹：黄红不规则大块；中心明黄、外缘深墨、再外一圈水彩飞溅。
- 修正带：暖白缎带配炭黑阴影；它是“擦除反制”而非普通白弹，必须有小型齿轮/卷轴端。
- 调色盘卫星：四色硬边色块围绕主体；不要被做成普通魔法球。
- 圆规冲刺：朱红半圆加锐利针脚，轨迹起点有金属灰针尖。
- 数位笔无人机：青色像素短线 + 深色方形笔尖，区别于水彩和墨水。

## 敌人方案：擦除教团

敌人不做“彩色史莱姆”。它们是文具/空白/碎纸构成的反创作阵营，白色实体需使用深灰描边与灰蓝阴影，保证不会融入纸底。

| 现有类型 | 草案外形 | 尺寸建议 | 功能预警 |
| --- | --- | ---: | --- |
| chaser | 撕纸小团，中心黑色撕裂缝 | 20–28 px | 无；数量本身是压力。 |
| eraser | 带纸屑的双段橡皮擦，灰粉主色 | 36–44 px | 侵蚀前闪一圈暖灰虚线。 |
| shield | 白纸折盾/回形针甲壳 | 36 px | 冷蓝菱形护盾片。 |
| shooter | 圆规眼/订书机嘴的小纸偶 | 32 px | 洋红弹道起手闪。 |
| summoner | 翻开的空白速写本 | 36 px | 紫灰撕页飞出。 |
| paper_plane | 折纸飞机，缺口像咬痕 | 20 px | 冷蓝尾迹。 |
| boss_prism | 破碎白纸棱镜，裂缝透彩 | 80 px | 护盾片可见倒计时裂纹。 |
| boss_roller | 巨型滚筒橡皮擦 | 120–160 px | 运动方向有宽白擦带和纸屑。 |
| boss_slime | 流动的空白液/涂改液 | 120 px | 外沿炭黑、核心乳白，避免纯黑团。 |
| boss_eraser | 四角磨损的终极橡皮擦碑 | 160 px | 多段红灰裂纹、擦除波纹。 |

## UI 方案

战斗 HUD 的基础是“深墨书写 + 速写本纸质文具”，不是重纹理卡牌。底色用 88–94% 不透明的暖白，信息用近黑，稀有度和危险状态才进饱和色。每个组件像贴在页面边缘的一张小标签：不规则墨线框、局部胶带或图钉、轻微投影；但文字和数值必须用规整的高可读字体。

- 生命：左上角 3 px 墨线圆角纸条；血量为朱红颜料填充，受伤短暂出现纸屑裂边。
- 经验：一根位于屏幕下缘的细群青笔刷线；满级时笔头向右弹出小墨滴。
- 技能选择：3 张 320×440 的纸卡，顶部是大图标，底部为强对比文本；稀有度只染卡片角标，不染全文。
- 守卫模式：画作完整度是带“被擦白缺口”的小画框；警报为橡皮擦形状而非通用红色感叹号。
- 神笔马良画板：全屏暖纸，半透明靛蓝目标轮廓；操作层只保留「取消 / 具现」两个大按键，避免抢走描线注意力。
- 结算/回放：墨线细画框包住玩家作品，外页带速写本页码、胶带角和手绘播放控制；不使用独立的现代玻璃拟态 UI。

## 地图装饰方案

地图保持留白，装饰只为路径尺度、画布感和战况层次服务；不得遮挡攻击、敌人或玩家笔迹。

| 模块 | 建议尺寸 | 作用 |
| --- | ---: | --- |
| 画纸边缘/胶带角 | 128×128 / 64×64 | 标记地图区域，低对比。 |
| 颜料盘/水杯/笔刷 | 32–64 px | 稀疏地标；非碰撞。 |
| 纸屑和撕边 | 16–32 px | 敌方路线/擦除后的环境反馈。 |
| 夹子、图钉、回形针 | 16–24 px | 作为小尺度地面装饰与技能联动暗示。 |
| 马克笔擦痕 / 铅笔排线 | 64–128 px | 低饱和、低 alpha；作为地面分区与手绘痕迹，避开战斗关键区。 |
| 守卫模式原画框 | 256–512 px | 保护目标视觉锚点，外框深墨、内画高可见。 |

## 生产顺序（确认后）

1. 先做 eraser、chaser、命中/受击/死亡反馈各一套，实机验证纸底可读性。
2. 再做收藏家 + 圆头画笔的完整 32×32 动画切片，锁定精灵语言。
3. 扩展其余 7 名角色和武器图标。
4. 最后制作 HUD、选择卡、神笔画板、守卫模式专用 UI 与地图模块。
