# 主菜单背景编辑约束

内置 image_gen；单次精确编辑。以下为生成约束归档摘要，不是工具调用提示词的逐字副本。

```text
Use case: precise-object-edit
Asset type: production game main-menu background
Input image: main-menu-v2.png, the approved layout and the only edit target.
Change only: remove the four right-hand menu button frames, their labels,
the selected red pointer/underline, and the bottom keyboard/settings/exit controls.
Fill those removed areas with the same unobtrusive dark paper and existing scene.
Keep: the large DON'T ERASE ME dry-brush title and Chinese subtitle;
the collector, red scarf, brush sweep, eraser enemies, ruins, paper texture,
original framing, proportions, composition and charcoal/ivory/rust-red palette.
Do not redesign the illustration or add controls, text, ornate decoration,
new characters, gradients, bright colors, or a watermark.
Output: an opaque full menu background; live controls will be implemented in code.
```

项目内保留 PNG 源图；WebP 仅为运行编码副本。两张已确认 UI 基准图不覆盖。
