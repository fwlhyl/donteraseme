人物是方向示意，不是已批准的角色设定或可直接使用的精灵图。生成图中文字、计量条填充比例、弹药格数量与游戏尺寸，在正式实现时需用真实数据及 DOM / Canvas 精确呈现，不直接把整张 UI 当运行贴图。现在不新增技能快捷栏、擦除抗性或其他机制。
