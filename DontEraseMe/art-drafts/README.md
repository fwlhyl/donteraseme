## 评审建议

1. 先确认「手绘速写本战场」这一大方向，以及不规则黑描边、暖纸底、马克笔色块的比例。
2. 再确认角色中偏好的剪影、服装密度与萌感；概念板不是逐帧素材，后续会按 32×32 重绘。
3. 确认敌人的“擦除教团”是否维持无彩色为主、仅以功能色做警告的阵营规则。
4. 确认 UI 是“可读的纸质文具”而非全水彩插画，避免战斗 HUD 发灰。

生成方式：内建 ImageGen；概念图须经确认后，才会整理为可接入的透明 PNG、精灵图和 UI 九宫格。
