# 画画回放：实现与验收（2026-10-01）

## 当前行为

开局自动记录，结算后点击“回放本局画作”。固定全画布视角，默认 30×，可切换 10× / 60×，暂停、重播、跳过或 Esc 返回结算。仅保留当前一局，离开结算/重新开始后释放；不导出视频、历史日志或上传网络。

创造模式记录画布真正收到的笔迹，包括时间消隐和橡皮擦。守卫模式在原画基础上重播玩家笔迹、软擦和像素修复。马良画板保存为独立数据，在对应时间显示小图，不叠到世界作品上。人物和敌人的战斗画面本身不录制。

## 模块

- `StrokeLog.ts`：显式 Canvas2D 代理，原始绘制照常执行，填充/描边的几何和样式存入紧凑数字块；随机效果保存已生成的坐标。读取游标按时间和每帧事件预算播放。
- `ArtReplayRecording.ts`：本局生命周期、冻结最终作品、极高负载下的压缩快照尾段。
- `ArtReplayPlayer.ts` / `artReplay.css`：回放界面及独立循环，用新画布恢复结果，不驱动 ECS 或金币结算。
- `DefensePainting`：擦除和修复回调；回放用另一实例执行相同算法。目前初始画仍是内置“守护之花”。

数字日志预算 96 MiB，压缩快照预算约 16 MiB；达到日志预算或出现不支持的未来绘制指令时，后续片段转为默认 5 秒间隔的快照，预算压力下加大间隔，界面给出提示。最终作品另存一份原尺寸画布，因此末帧与 PNG 导出一致。画布本身也会占用内存，上述数值不是整个游戏的内存上限。

## 验证

构建：`npm run build`。

浏览器回归脚本：`scripts/test-replay.mjs`，需要本地 Vite 服务器、Chrome、可用的 Playwright。默认 URL 为 `http://127.0.0.1:5174`；可通过 `REPLAY_TEST_URL` 和 `PLAYWRIGHT_MODULE_PATH` 指定服务器和现有 Playwright 的模块路径，无需更改游戏依赖。

脚本使用隔离浏览器存档：验证基础画笔/曲线/变换/半透明/擦除像素结果、守卫软擦与修复、画板通道、内存预算、20 分钟模拟时间的合成笔迹流、实际武器绘制、暂停/倍速/跳过/自然结束、返回结算不重复发币、重开清空旧日志、窗口缩放不擦掉原作品，并保存界面截图。

自动合成 20 分钟记录流不等于完成一局真实 20 分钟的战斗性能验收。高阶技能组合与长局帧率仍需正常试玩。

## 手动验收

1. 创造模式射击并移动约半分钟，死亡结算后回放；检查笔迹生成、倍速、暂停、从头和跳过。
2. 返回结算保存作品；再次回放，检查金币不再增加。
3. 守卫模式让橡皮擦侵蚀，再攻击修复，结算回放中检查原画的变化。
4. 使用一次神笔马良，检查回放角落出现对应图案。
5. 回到主菜单重开，确认没有上一局笔迹；试玩期间先冻结源码修改，避免 Vite 自动刷新。
