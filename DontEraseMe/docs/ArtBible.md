## 一、全局视觉语言（一句话定位）

**白纸细线单色世界**：灰白纸面 + 黑/灰细线，像一幅放大的手绘地图；外围细节成组、中央活动区留白；角色用简练的黑白形体；**唯一的饱和色来自战斗与绘画的笔迹**。

**不变的核心钩子**：**玩家荧光笔迹永远是最亮、最艳的主角**——这是「别擦掉我」的命根子。世界必须是单色，让笔迹在画面上始终跳出来。

**渲染铁律**：这是一套**会动的手绘世界**，吸引力来自线条、造型和颜色逐渐积累，不来自光照。禁止立体阴影、夜景灯光、喷枪渐变、摄影贴图。

## 二、锁定调色板（Locked Palette）

### 2.1 单色明暗骨架（世界无彩色）

| 名称 | 色值 | 用途 |
| --- | --- | --- |
| 纸面 | `#faf9f5` | 全局底色（近白，不是纯白） |
| 深线 | `#232220` | 角色轮廓、关键形、攻击预告（近黑） |
| 中线 | `#44423d` | 次级轮廓、屋顶、栅栏 |
| 浅线 | `#7b786f` | 环境细线、纹理、草簇、窗框（最浅） |
| 填充-白 | `#ffffff` | 眼睛巩膜、笔尖等高光 |
| 填充-浅灰 | `#f2f0ea` / `#e8e5dd` | 道具平涂 |
| 敌人主体 | `#cfcbc0` | 浅灰（比纸暗一档、比玩家亮一档） |

### 2.2 玩家笔迹（不属于世界，永远最亮最艳）

12 种武器的**多色荧光笔迹**是画面最高优先级，唯一饱和色通道。世界必须单色，保证笔迹是全场唯一色彩。

### 2.3 禁用

立体阴影 / 夜景灯光 / 喷枪渐变 / 脏灰中间调 / 摄影贴图 / 环境里的任何彩色。

## 三、可读性铁律（Readability Invariant —— 本方向的验收标准）

**同一场景在「开局空白 / 战斗中 / 满地彩色」三态下，玩家、敌人、攻击始终一眼可辨。** 可读性靠**明度 + 线重 + 填充/线框 + 动画**，**不靠颜色**（颜色会被笔迹淹没）。

三级体系：

| 层级 | 画法 | 说明 |
| --- | --- | --- |
| 环境线 | 浅灰、细（最轻） | 只在外围密集，中央活动区留白 |
| 角色 / 敌人 | **不透明填充** + 深色关键轮廓（中重） | 值分离：玩家深色实心、敌人浅灰实心 |
| 攻击预告 | 粗黑 + 白内环 + 短动画 | 永远压在笔迹之上，不靠颜色区分 |

**铁律：浅色敌人 ≠ 白色。** 白纸世界里白色 = 纸 = 消失（已验证：白色敌人要看第二遍才发现）。用中间偏浅的灰 `#cfcbc0` + 深轮廓 + 内部特征（深橡皮套、大眼）兜底。

---

## 四、轮廓与比例规则（Silhouette & Proportion）

- **角色 64 px 站立规格**、碰撞半径 20（玩法不变）。
- **不透明黑白主体**：角色用 2–3 个明度块 + 大而简的眼睛 + 一个朝向提示；手脚省略成「读得懂的剪影」。
- **利落剪影**：靠轮廓一眼可辨，不靠发丝/衣褶堆细节。
- **轮廓线有粗细变化**：外轮廓粗、内部细节细；不是每处细节都加黑描边。
- **敌人锚定**：浅灰实心 + 深轮廓 + 深橡皮套 + 大眼；与玩家深色块形成稳定值反差。
- **负向约束**：禁止臃肿墨团身体、禁止四肢不清、禁止透明线框（后期笔迹铺满会糊）。

---

## 五、场景构图（Scene Composition）

1. **中央活动区留白**：可走地面 = 硬约束；所有小物件、密集纹理、草簇一律拒绝进入中央（与碰撞区共用同一多边形）。
2. **密度堆在外围**：建筑、工作台、画具、栅栏、木箱、木桶、石头、草簇，成簇排布（工坊簇 / 画架簇 / 花园簇）。
3. **细线 ≠ 一样细**：背景线最轻，人物/敌人关键轮廓略重，攻击提示最清楚。
4. **手绘感**：墙会歪、角不是 90°、屋脊下垂、轮廓过笔、线条轻微抖动——不做工整网格。

---

## 六、光照与投影

- **无立体光照**。世界是平涂单色线稿，明暗只来自线重与填充，不来自灯光。
- **投影**：用稀疏单向短排线（hash marks）暗示，克制、不做交叉排线、不做软阴影。
- **动画时钟**：全部模拟 dt，暂停不消耗，大 dt 截断。

---

## 七、UI / 图标规范

- **词汇**：墨线 + 白纸，与场景同一套 monochrome line。
- **面板**：白/浅灰纸面 + 黑灰细线框 + 墨线文字；无立体、无霓虹。
- **图标**：单色线稿。
- **禁用**：彩绘文字、心形徽章、emoji、彩虹品质、大圆角实底卡片。

---

## 八、动效指南（Motion Guidelines）

- **攻击预告**：粗黑轮廓 + 白内环 + 蓄力画入/呼吸动画；危险永远压在笔迹之上。
- **hit-stop**：命中瞬间冻结 30–80ms（默认 40ms，参数可调）。
- **缓动**（禁线性）：`ease-out` / `ease-out-back` / `sine`。
- **角色动作**：剪纸式（身体不横摆、腿随位移迈步），不逐帧噪点。

---

## 九、错误清单（Visual Mistakes to Avoid）

1. ❌ 立体阴影 / 夜景灯光 / 喷枪渐变 / 脏灰中间调 / 摄影贴图。
2. ❌ 每处细节都加黑描边（只在外轮廓和关键形加）。
3. ❌ 浅色敌人做成白色（= 纸 = 消失）。
4. ❌ 角色透明线框（后期笔迹铺满会糊）。
5. ❌ 中央活动区塞满纹理/小物件（地面线、敌人、笔迹混在一起）。
6. ❌ 环境里出现彩色（抢走笔迹的唯一色彩地位）。
7. ❌ 工整网格 / 直角 / 直线（不像手绘）。
