# 暗纸手绘 UI 第二版 — 实现与验收

2026-10-17。当前可交付试玩，视觉最终验收由用户确认。

## 风格基准

以 `art-drafts/dark-paper-ui-2026-10-16/main-menu-v2.png`、`combat-ui-v2.png` 为唯一已确认 UI 方向：炭灰粗纸、米白干笔、少量锈红、克制的磨损矩形线框。两张原图 SHA-256 未变化。

主菜单使用内置 image_gen 从确认图清理出的背景，保留标题、人物与挥笔构图，移除原位图按钮后接入真实 HTML 控件。背景源稿、编辑约束与校验值保存在 `art-drafts/dark-paper-ui-2026-10-17/`；运行 WebP 约 378 KB。代码原生 SVG 提供纸纹、框线和十二种画笔图标。

## 已接入范围

- 主菜单：创造、守卫、纯画画、画廊四入口，设置/退出、键鼠提示；16:9 构图完整保留，窄竖屏改为上下布局。支持键盘聚焦，切换语言不移除图标。
- 出击准备：角色/画笔选择与锁定状态、共享金币、购买、详细信息、守卫画作选择/导入。滚动列表与详情面板分开，窄窗口不让详情溢出边框。
- 战斗 HUD：左上生命和经验细条、单色画笔图标、分组弹药刻度、装填/空弹/近战/载具状态、得分金币评级；不再有实底大卡片和心形徽章。
- 神笔：底部中央画笔框、G、真实灵感数值及充能条；满条与驾驶状态有文字提示。计量只读现有系统，未改变充能或载具规则。
- 小地图/暂停：右上不规则米白框、炭灰地图和锈红敌人点；暂停键紧邻地图。
- 守卫 HUD：画名、完整度、剩余时间；被擦除/低完整度警告沿用实际状态。较窄桌面移至左下，与右下神笔条分开。
- 纯画画工具栏：统一纸墨配色，保留真实颜色样本、已解锁画笔选择、计时、暂停和完成。
- 二级界面：暂停/设置/音量、强化/觉醒、神笔描绘板、结算、命名保存、回放、画廊导航/列表/详情全部统一。暂停和升级弹窗层级高于 HUD。

## 明确不改的内容

本轮不替换战斗场景、角色、敌人、手持武器、技能实体、音乐或音效。主菜单人物是已确认插画的一部分，不代表新角色精灵已接入；独立手脚角色 v2 已记录为用户暂定认可。

纯画画的白画纸、色样、守卫原画与玩家彩色笔迹是作品内容，不套 UI 滤镜。保存、导出与回放的画作像素不因 UI 主题变化而重着色。3D 画廊只换操作界面，展厅模型/灯光不改。

战斗数值、敌人数量、地图碰撞、画作裁剪、解锁价格、结算与存档规则不改。纸纹为静态资源，不增加逐帧噪声或模糊动画；本轮不宣称解决此前 Mac 后期性能反馈。

## 验证

已执行并通过：

```sh
npm run build
node scripts/test-combat-hud.mjs
node scripts/test-minimap-performance.mjs
node scripts/test-paper-ui.mjs
node scripts/test-drawing-mode.mjs
node scripts/test-shared-progression.mjs
node scripts/test-replay.mjs
node scripts/test-gallery.mjs
node scripts/test-defense-artwork.mjs
```

`test-paper-ui.mjs` 使用独立 Chrome 上下文和测试存档，检查四入口、初始颜色、1366/1024/390 宽度菜单、语言图标、生命/弹药/神笔、暂停、升级/觉醒、描绘板、守卫、纯画画、结算、命名保存、回放、画廊返回，以及未捕获运行错误。稀有 UI 状态在测试内注入，不改正式玩法。20 张截图保存在 `art-drafts/dark-paper-ui-2026-10-17/screenshots/`，已目视核对关键界面。

额外回归覆盖共享金币、PNG、20 分钟截止、保存失败/重试、守卫导入/裁剪/开场、回放成品一致性、画廊 WebGL 降级与释放。构建只有既有 Three.js 画廊分块超过 500 KB 的警告，无类型或打包错误。

注意：这些是当前本机浏览器的功能及布局检查，不等于 Electron 打包验收、真实 20 分钟高负载帧率验收或用户最终审美批准。
