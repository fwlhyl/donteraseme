# 敌人步态、夜景衔接与后期性能

## 第二轮：开局数分钟卡顿反馈（2026-10-13）

下述更新晚于本文第一轮结果：

- `MovementSystem` 先收集墙体，保持原墙体顺序/激活检查，不再为每个角色扫描全部子弹、粒子和经验球。200 敌人 + 800 非角色实体、30 次更新的无墙测试中，墙体标签检查 6066060 → 30030，角色坐标逐项一致。
- `CourtyardGeometry` 缓存安全格的保守净空半径。只有整格确定远离边界时跳过多边形计算，墙边、巨大或异常半径仍用原精确算法。25000 个随机 fits 对照及 1200 组投影/移动/线段对照一致。
- 敌人互相分离采用动态格索引，并保留原始 i/j 次序。推挤后更新双方，离开候选覆盖区时只重查未访问的尾部。600 分散敌人候选对 179700 → 59；600 分簇敌人 4 帧 691200 → 6657；600 完全重合敌人保守回退，仍为 359400 对/2帧，不能承诺相同收益。
- 小地图先过滤非玩家/敌人/载具实体，10000 个无关弹体/粒子无需读组件，维持原刷新频率和坐标。
- `StrokeLog.withPaintBoundary` 与 `Game.loop` 每帧共享世界裁剪、缓存变换读取，保留每次绘画和原消隐时序。400 笔固定变换测试：原生 clip 400 → 1，getTransform 2000 → 2；事件数、顺序及所有记录数字一致。批处理要求同步、平衡 save/restore，清空/重置画布必须在范围外。
- 浏览器实绘/回放核验：1620 事件记录逐数一致，原/新栅格仅 3/281600 个通道出现边缘误差，平均绝对差 0.000096。原尺寸 2700×1800 画布的加速 300 秒笔迹流保留 162000 事件、日志 24.75 MiB，无快照降级；此测试不包含全战斗，也不等价于 5 分钟真实游戏 FPS。

新增测试：`test-movement-performance.mjs`、`test-minimap-performance.mjs`、`test-stroke-recording-performance.mjs`；扩展 `test-performance-combat.mjs`。浏览器入口：`/art-drafts/recording-performance-review.html`。完全密集怪群、全画布消隐和高阶技能叠加仍可能成为热点，未宣称完全消除卡顿。

## 画面调整

- `DoodleEnemyGait.ts` 为追逐者、橡皮擦、盾卫、射手、召唤者及普通/滚筒/橡皮首领共 8 类地面敌人配置身体下沿遮罩和独立腿。复用原图尺寸/枢轴，只替换固定脚；按实际位移交替迈步，顶墙/冻结/传送后停脚。身体无移动横摆或挤压，仅轻微上下；攻击回弹和短受击反馈保留。飞行形状、史莱姆、黑洞保留各自运动语言。
- `DoodleFloor.ts` 移除守卫的矩形虚线框、创造模式双描边。玩法地板内缘约数十世界像素渐融到原夜景，中部仍是安静暗底。边界几何、移动/笔迹裁剪与导出不动。Canvas filter 不可用时退回无描边的直接绘制。
- 地板以 1536px 宽离屏缓存，模糊只在生成缓存时计算，最多保留 4 种尺寸/主题。静止镜头场景最多按 30Hz 灯光帧重绘，移动镜头每帧重绘，不影响角色动画。
- 灯的基础时间加速为首版 2.2 倍；守卫故障灯约每 3.4–4.5 秒出现一次局部柔和低谷，灯芯和对应光斑同相、不同灯异相。仍响应游戏暂停和系统减少动态效果偏好，没有全屏闪光。

## 性能实现与保护

1. `CollisionSystem`：敌人数量达到 48 时，为子弹建立每帧中心点空间网格；宽筛保留原 AABB，候选按原实体顺序验证，避免改变穿透、护盾和随机触发顺序。击退/引力移动立即更新索引；觉醒地雷与长线/密集大候选回退原遍历。敌人互相分离保留原顺序，只缓存本阶段组件、用轴向距离跳过不可能碰撞的远对。
2. `GraffitiSystem`：长路径建立增量线段索引，只精确检查相关格；始终按原线段次序寻找首次交点。短路径、跨越大范围及异常坐标保留线性回退。点数、闭合图形、伤害区域和笔迹均不删减。
3. `RenderSystem`：仅对边界可确定的普通敌人、粒子和经验球做屏外绘制裁剪，再排序可见实体。Boss、投射物、技能、长线、骨骼附件等保守保留；屏外敌人的动画时间仍推进，回到屏幕不会补播旧受击；数位笔寻找目标仍包含屏外敌人。
4. 背景地板缓存和静止镜头重用减少重复绘制。没有为了性能降低资源清晰度、画布尺寸或关闭画作日志。

## 自动验证结果

- `test-performance-combat.mjs`：600 敌人 + 900 子弹的固定稀疏场景，组件读取 785863 → 21013；单轮 Node 计算约 15.35ms → 8.06ms（仅这次运行参考，不是浏览器 FPS）。混合武器/盾/暴击/链条/穿透/跨格击退差分，HP、位置、随机次数、声音和画布命令一致。
- 同脚本：5000 点固定长线，精确线段相交测试 12452545 → 8448。随机画线首次相交与闭合多边形一致。
- `test-render-performance.mjs`：240 敌人 + 120 粒子 + 160 经验球、每类20个可见的固定场景，绘制调用 1520 → 160（89.5%减少）。保留区域的绘制、z顺序、alpha、动作连续性、屏震边缘、数位笔瞄准一致。
- `test-floor-cache.mjs`：120帧只生成1次地板/模糊，主题缓存复用、模式坐标、状态恢复与旧Canvas回退。
- `test-doodle-motion.mjs`、`test-player-artwork.mjs`、`test-doodle-skills.mjs`、`test-doodle-lights.mjs`、`test-scene-layout.mjs`、`test-audio.mjs`、`test-combat-audio.mjs`、构建及四个审阅入口类型检查通过。
- 浏览器：敌人原图/分层对照检查8类；创造/守卫场景渐融审阅；正式创造模式移动、射击扣弹、受伤、暂停，控制台无error/warn；声音设置跨刷新保存且验收后恢复80%总音量。

以上不是用户设备后期 FPS 保证。敌人分离仍保留 O(E²) 原顺序；整画布消隐、守卫原画同步读像素及极密技能仍可能是后续热点。没有在本轮改消隐/录画的时序，以免作品或回放发生变化。真实20分钟长局与打包设备压测尚待实测。
