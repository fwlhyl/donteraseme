## 执行规矩

1. 每完成一项：`npm run build` 通过 + 跑起来冒烟验证，再开始下一项
2. 设计决策不自行更改；未定数值/文案用下方默认值表并标注「待调参」
3. 不破坏无尽模式现有行为（改动前先跑一局基线）
4. 代码风格照旧：手写 ECS、Game.ts 单体、window CustomEvent 事件总线
5. 每完成一项向用户报告：改动文件 + 验证结果

## T1 金币系统最小版（约 1 天）

**目标**：金币持久化 + 角色解锁商店（武器免费）。

**现状与参考**：局内金币已完整（怪掉金币 goldValue 1~500、`Score.coins`、收藏家金币倍率、局内买创作时间）；持久化/商店/解锁全无（localStorage 只有画框）；8 角色 12 武器当前开局全可选（`CHARACTERS` 配置 + `PlayerFactory` 的 `characterId` 选择）。

**实现要点**：
- localStorage 存累计金币；局末结算把 `Score.coins` 累加进去
- 商店 UI：8 角色按解锁状态显示（已解锁可选中/未解锁显示价格）
- **收藏家免费初始**（与设计案「初始人物」一致）
- 角色选择入口复用现有选人流程，未解锁置灰

**验收**：买角色 → 重启游戏仍解锁；收藏家开局可用；无尽模式回归无破坏。

## T2 笔迹日志 Stroke Log（约 0.5 天，共同地基）

**目标**：在现有绘制调用点旁追加轻量记录，供回放/守卫印画复用。

**实现要点**：
- 记录点：TrailSystem（移动轨迹）、WeaponSystem（弹道轨迹）、GraffitiSystem / SkillSystem（填充/绽放事件）
- 格式见 `V11FeatureDesign.md` §0：`StrokeRecord`（move/shot 带 points；fill/bloom 带半径）
- **按距离抽稀 2~3px**；单局只存内存，结算后丢弃
- 热路径**禁止 new 对象**，复用数组

**验收**：打一局日志量合理（抽稀生效）、帧率无明显劣化。

## T3 作画回放（约 0.5~1 天，依赖 T2）

**目标**：结算屏"回放"按钮，快进重放整局作画。

**实现要点**：
- gameOver 屏加"回放"按钮：停主循环，requestAnimationFrame 独立驱动
- 按时间戳重放日志条目，**复用现有笔迹绘制函数**画到新全图画布（视觉与真实作画一致）
- 固定全图俯视（3000×2000 等比缩到屏幕内）；默认 30×，提供 10×/30×/跳过
- 高光跳过（可选优化）：连续 X 秒无笔迹直接跳帧

**坑**：日志只记"已画出的"——alpha 消隐/擦除不记录，回放是"理想完整版"（接受）。

**验收**：结算回放完整、速度控制可用、返回主菜单正常。

## T4 神笔马良 v2（约 2~3 天，依赖 T2）

**目标**：杀敌攒条 → 玩家按键开板（暂停）→ 照图纸临摹 → 识别 → 临时武器。

**实现要点**：
1. **进度条**：杀敌充能（复用击杀事件）
2. **开板**：条满后按 **E 键**触发；开板瞬间**游戏暂停**（时间停止，主循环加 paused 标志）；全屏画板 UI 显示图纸
3. **图纸**：坦克 / 飞机 / 机器人三张（模板=图纸同源轮廓点列，识别与显示共享一份数据）
4. **识别器**：$1 一元笔画（Wobbrock 2007，~200 行 TS）——画板笔迹 → 重采样 64 点 → 质心平移 → 单位缩放 → 标准角旋转 → 模板路径平均距离打分 → 超阈值命中
5. **收益**：命中 → 对应临时武器（满额 20s / 打折 10s，待调参）；召唤本体复用 **SummonSystem 火柴人助手**
6. **放弃**：ESC 取消，进度不返还
7. 画板笔迹是**独立 UI 表面**，与 trailCtx 完全隔离（无需噪音过滤）

**验收**：攒条 → 开板 → 描 → 召唤出现 → 倒计时消失；ESC 正常；暂停期间敌人不动；三张图纸各自能识别（含故意画歪不命中）。

## T5 守卫模式完整版（约 4~6 天，依赖 T2+T3 回放引擎）

**目标**：开局印画 → 敌人分兵啃画 → 玩家守画补画 → 三类结束条件。

**实现要点**：

1. **分层画布**：`paintingCanvas`（原画层，世界尺寸，在下）+ 现有 `trailCanvas`（在上），渲染顺序原画先画笔迹后
2. **印画 = 笔迹化播放**：画 = stroke log，用 T3 的回放引擎播放到 paintingCanvas。内置画先用 1 幅手写测试 stroke JSON（太阳/山/花简笔画）验证链路，正式画待美术线产出替换
3. **上传图笔迹化**（玩家守自己的图）：`<input type="file">` → 解码 → 缩放 + **智能内容裁剪**（边缘检测找内容包围盒，去白底）→ 灰度 → **Sobel 边缘检测** → 阈值 → **轮廓追踪（marching squares）** → 折线转 stroke log（**线宽 3~6px**）→ 播放。处理结果存 **IndexedDB**（可选历史图）。纯本地无分享
4. **软擦**：橡皮擦敌人对**两层**都做 `destination-out`，**alpha≈0.4**（擦几遍才擦没，"半褪伤疤"过渡态）
5. **分兵 AI**：敌人行为分两类——追玩家的 vs **直奔画**（走到画内容区停留擦除）
6. **像素级修复**：玩家笔迹落在**原画内容包围盒内** → 同一笔迹也画到 paintingCanvas（source-over 加回像素，残存率回升）；包围盒外只画 trailCanvas
7. **残存率**：每 3 秒 `getImageData(paintingCanvas)` 统计 alpha>0 像素 / 开局基准（勿每帧）
8. **胜负**：玩家死亡 = 败；**画被完全擦没 = 立即失败**（人活着也算败）；**守满 20 分钟且画还在 = 胜**
9. **波次**：复用 WaveSystem，敌人构成以橡皮擦类为主，节奏与无尽错开
10. 模式入口：主菜单模式选择（无尽 / 守卫）

**验收**：印画 → 敌啃 → 残存率降 → 玩家补 → 回升；三类结束条件均可触发；上传任意 jpg 能转线稿且可守；无尽模式回归无破坏。

## 全局坑与提醒

- **状态机**：running / paused(马良板) / replay / gameover 建议统一进 Game 状态字段，马良暂停与回放别各自为政
- **性能**：热路径禁 new；getImageData 只在守卫模式按 3 秒采样
- **分层渲染顺序**：paintingCanvas 在下、trailCanvas 在上，别画反
- **i18n**：新文案先中文，接入现有 i18n 机制（如有），文案表后补
- 每完成一项立即让用户验收，勿积压到全部做完
