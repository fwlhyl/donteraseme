# 像素人物制作标准（2026-10-27）

用户已明确认可收藏家的代码绘制人物、武器分离和程序动作，认为这种方式比图片／视频生成模型更流畅。后续人物沿用本标准，逐个制作、在实际对局中验收。

## 形象与尺寸

- 采用当前收藏家的成熟、克制像素造型。保留简洁轮廓，通过发型、衣领、服装剪影、背包和专属配件区分角色。
- 细节以 2～4 像素的成组色块组织，参考收藏家的八色低饱和材质分层；面部可以省略眼睛。限制零碎纹理、幼态比例和过大的手脚。
- 以 64px 为统一绘制坐标，游戏基础显示高度为 52px。参数集中在 `src/config/PlayerPresentation.ts`。
- 基础受击／碰撞半径 16.25，和原 20 半径按 52/64 同比例缩放。敌人接触、敌弹、墙体均读取真实半径；体型升级同步影响显示和碰撞。
- 当前其余角色共用收藏家样机，尚不代表全部角色美术已完成。

## 统一制作方式

- 优先使用代码分层绘制身体、头部、双腿、配件，武器作为独立绘制部件绑定。外部图片和视频可提供参考，不替代可控的运行时动作。
- 后续角色复用当前动作输入接口：实际移动方向、步态相位、待机呼吸、攻击、受击、换弹进度。角色特色通过形象及有限的局部动作体现。
- `DoodleMotion` 根据模拟时间和实际位移采样；角色显示状态不写回移动、伤害、冷却或弹药数据。

## 动作约束

- 行走有支撑脚和抬脚阶段，停步自然收脚。身体直立，仅微小上下起伏，不来回左右摇晃。
- 待机有可辨的轻微呼吸、头部／衣领回落；脚底站稳。移动、射击、受击时减弱，换弹和冻结时抑制。
- 移动转向响应约 42/s；90° 转向约 100ms 内靠近目标。鼠标瞄准沿用即时方向，左右朝向只留很小的稳定区。
- 持枪靠近胸口，手臂短且有肘部。枪械独立瞄准，朝上时仍能看见枪管；武器不带着身体整圈旋转。
- 射击采用短促后坐、快速回稳、枪口处的小像素闪光。换弹分压枪、装填、归位三个阶段，读取包括属性加成在内的真实计时器。

## 每批验收

1. 同时查看 52px 实际尺寸和 4 倍放大，检查静止、前进、倒退、左右和朝上瞄准。
2. 检查待机、射击、受击、换弹及动作切换，确认持枪握点和身体层次正确。
3. 检查 30/60/120/144Hz 的模拟时间一致性，以及停止、暂停、冻结和瞬移时的表现。
4. 检查敌人接触／敌弹受击范围与显示尺寸一致；确认体型升级也同步缩放。
5. 在游戏内测试再确认；预览页与游戏必须调用同一份人物和武器绘制代码。
