## 一、角色风格：锚点 = 白纸细线单色角色（值分层）

### 方向（2026-10-24 定案，替换「混乱大枪战 2」锚点）

世界已锁定为白纸细线单色（见 `../ArtBible.md`），角色随之改为**不透明黑白形体**，靠明度值分层与简练剪影辨识，不再走 Q 版彩色卡通。

- **玩家**：深色不透明实心（近黑 `#232220`）+ 白巩膜黑瞳 + 朝向提示（笔/武器）。
- **敌人（橡皮擦）**：**浅灰**不透明实心 `#cfcbc0`（不是白色！白色 = 纸 = 消失）+ 深轮廓 + 深橡皮套 + 大眼。
- 两者落在白纸明度轴两端（深 vs 浅灰），一眼可分；满地彩色笔迹下仍靠明度 + 填充兜底，不靠颜色。
