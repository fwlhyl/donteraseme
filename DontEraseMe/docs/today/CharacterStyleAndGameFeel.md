## 一、角色风格：锚点 = 《混乱大枪战 2》

### 参照来源与核心问题

4399 小游戏《混乱大枪战 2》（游影工作室）——Q 版卡通枪战的 2D 小人版。角色设计"很符合用户的形象"。

**核心问题诊断（用户原话）**："其实之前设计的人物还可以，但是让他真正做的时候，又变成很臃肿的模型。"

→ 概念设计是过关的，**失真发生在生成执行环节**（AI 生图把利落的小人画成了墨团式臃肿身体，现役 heroes-body-v2 即此结果）。所以风格锁的重点不是换方向，是**加防臃肿约束 + 参考图锚定**，让重做不再跑偏。

### 执行步骤

- [x] **第一步（用户）**：发参考截图 ✅（`20261013-111824.jpg`）
- [ ] **第二步（AI）**：提炼风格锁 = 以混乱大枪战 2 人物为锚 + **明确负向约束**（四肢清晰、轮廓利落、禁止整块墨团身体、禁止臃肿）+ 配色规律 → 写成可复制的提示词模板
- [ ] **第三步（AI）**：与现役资源 `src/assets/doodle/heroes-body-v2.png`（土豆式墨团身体 + 代码画的腿）逐项 diff → 重做成本评估（图集重生成 / 动画接入改动量）
- [ ] **第四步（拍板）**：锚点锁定

### ⚠️ 锚点纪律

角色方向已第三次动（水彩 → 涂鸦墨团 → 本锚点）。锚点一旦定案就**锁死勿再改**——角色是最大的美术批量，后面还有商店页素材和 demo 素材等着，改方向的窗口不多了。

### 验收三问（贯穿所有美术批次）

1. 主题对吗（是这套风格吗）
2. 和同批其他资源风格统一吗

三问全过就用；问出"否"就是给 Codex 的修改清单。
